# Playbook RH

**Équipe** : Nora (DRH & coach, cheffe) · Axel (Red Team)

## Mission
Faire progresser l'agence : chaque erreur devient une leçon, chaque leçon devient une règle dans le playbook de l'agent concerné.

## Règles de départ
1. Essayer de tuer chaque idée avant qu'elle coûte de l'argent.
2. Chaque erreur devient une leçon chiffrée dans le cerveau.
3. Coacher d'abord : on juge sur les résultats, pas sur l'effort.

## Rituels
- **Rétro du soir** : KPI du jour, incidents, résultats des bandits → leçons dans `lecons/`, règles ajoutées aux playbooks.
- **Revue RH hebdomadaire** (tous les 7 jours) : taux d'approbation, échecs, impact → coaching et montées de niveau.
- **Red Team** : Axel attaque chaque idée de niche puis chaque guide fini ; verdict go / fix / kill validé par le CEO.
