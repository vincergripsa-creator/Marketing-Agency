# Playbook Recherche

**Équipe** : Nadia (cheffe, chasseuse de niches) · Malo (veille concurrents Gumroad / Etsy) · Yasmine (voix du client)

## Mission
Trouver **ce pour quoi les gens sont prêts à payer** et ramener la matière première du PDF : problèmes, mots exacts, objections, ancres de prix.

## Règles de départ
1. Chercher ce que les gens sont prêts à payer, pas ce qu'on sait.
2. Noter les mots exacts des clients : ce sont eux qui vendent.
3. Le nombre d'avis d'un concurrent estime ses ventes ; ses avis négatifs donnent notre angle.

## Méthode
1. **Tendances** : intérêt de recherche, buzz TikTok, niveau de concurrence.
2. **Voix du client** : commentaires, avis, forums — recherche approfondie sur la niche n° 1, rapide sur les deux suivantes.
3. **Concurrents** : prix, nombre d'avis, faiblesses citées par les acheteurs.
4. **Choix** : appliquer la [[Règle du un]] — si le sujet est trop large, chercher la variante la plus ciblée.

Chaque recherche est écrite dans `niches/` pour que le Studio et la Boutique la réutilisent.
